Clinical entity recognition

Paste a free-text clinical note. The LLM extracts structured clinical entities (findings, procedures, medications…) as JSON — with negation, laterality and English normalization — and each entity is mapped to SNOMED CT through the same hybrid engine, using its normalized clinicalTerm as the query and its type as a hierarchy filter.
